# 江湖拾梦网站部署

当前待发布版本：**4.0.0**。游戏为中文浏览器放置 RPG，部署目录为 `public/jianghu/`，目标入口为 `https://phiagames.com/jianghu/`（访问 `/jianghu` 自动补斜杠）。首页作品区第一张卡片直接进入游戏，封面使用带哈希的稻香村 WebP。此说明不代表公网已经更新。

## 发布方式

将经过验证的静态网页版文件放入 `public/jianghu/`，保留原有相对路径。Vite 构建会复制到 `dist/jianghu/`。旧 `public/games/jianghu/index.html` 仅负责跳转并保留查询参数和片段；历史哈希资源保留以兼容缓存中的旧页面。

现有 `master` 分支工作流仍部署 GitHub Pages；迁移腾讯云后应上传整个网站 `dist/` 并配置 Nginx，不应将源码仓库地址作为玩家的资源地址。腾讯云配置位于游戏项目的 `deployment/tencent/`；切换域名解析前必须完成真实网站验收。

游戏目录只包含运行所需的 HTML、JavaScript、CSS 和图片。离线大文件、测试报告、浏览器配置、个人存档及部署凭据不应加入公开目录。游客模式不需要后端；账号模式需要独立的 HTTPS 账号服务。当前 `account-config.js` 的 `apiBase` 为空，真实账号登录尚未上线。

发布前验证网站构建、首页卡片跳转、子目录资源加载及游戏新建存档。发布后检查公开入口与版本，确认旧作品页面和工具入口仍然可访问。构建成功与线上可用应分别确认。

## 存档

游客进度保存在当前浏览器的本地存储中。存储键不依赖 URL 路径，所以同一 `https://phiagames.com` 下从 `/games/jianghu/` 跳转到 `/jianghu/` 继续读取原存档。不同设备、浏览器、域名以及本地离线 HTML 不会自动共享游客进度。

从离线版或其他域名迁移时，可在游戏设置中导出和导入游客存档。账号存档由服务器结算，不能上传客户端任意存档来取得正式账号奖励。4.0 的单主角模型迁移和旧档备份由游戏自身处理。

## 回滚

需要回滚入口时，恢复已备份的 `public/jianghu/`、`public/games/jianghu/` 和 `src/data/siteData.ts`，先验证两个入口及存档兼容性再发布。保留其它作品、工具、域名与发布配置；不要用旧网站整包覆盖当前网站，以免覆盖其它更新。

需要回退游戏版本时，可将游戏目录替换为此前已验证的同路径静态版本并同步首页版本文案。回退前确认目标版本的存档兼容性，玩家可先导出存档备份。
