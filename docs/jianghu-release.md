# 江湖拾梦网站部署

当前接入版本：**3.0.1**。游戏为中文浏览器放置 RPG，部署目录为 `public/games/jianghu/`，公开入口为 `https://phiagames.com/games/jianghu/`。首页作品区第一张卡片直接进入游戏，封面复用游戏中的稻香村场景。

## 发布方式

将经过验证的静态网页版文件放入 `public/games/jianghu/`，保留原有相对路径。Vite 构建会将这些文件复制到 `dist/games/jianghu/`；现有 `master` 分支发布流程继续负责部署 GitHub Pages。

游戏目录只包含运行所需的 HTML、JavaScript、CSS 和图片。离线大文件、测试报告、浏览器配置、个人存档及部署凭据不应加入公开目录。无需额外后端服务或数据库。

发布前验证网站构建、首页卡片跳转、子目录资源加载及游戏新建存档。发布后检查公开入口与版本，确认旧作品页面和工具入口仍然可访问。构建成功与线上可用应分别确认。

## 存档

游戏进度保存在当前浏览器的本地存储中，没有账号或云端存档。不同设备、浏览器、域名以及本地离线 HTML 不会自动共享进度。

从离线版或其他地址迁移时，在旧游戏的设置中导出存档，再到网站游戏的设置中导入。建议在切换设备或清理浏览器数据前导出备份。版本 3.0.1 沿用 3.0 的历程存档；更早版本的重置和备份行为由游戏自身的存档迁移逻辑处理。

## 回滚

需要撤下游戏时，只移除 `public/games/jianghu/` 及 `src/data/siteData.ts` 中 `id: "jianghu-shimeng"` 的作品卡片，并恢复后续卡片编号，再通过原有流程发布。保留其它作品、工具、域名与发布配置；不要用旧网站整包覆盖当前网站，以免覆盖其它更新。

需要回退游戏版本时，可将游戏目录替换为此前已验证的同路径静态版本并同步首页版本文案。回退前确认目标版本的存档兼容性，玩家可先导出存档备份。
