# 《江湖拾梦》网站部署

《江湖拾梦》是以白芦渡护送药车为开端的中文放置武侠游戏。首页的中英文作品卡直接进入游戏，封面使用发行清单指定的白芦渡图片。玩家可从[游戏官网](https://phiagames.com/jianghu/)开始，也可从[招式工坊](https://phiagames.com/jianghu/effects-gallery.html)查看战斗演出。

## 发布

1. 在游戏源码仓库生成网页与离线包。核验发行清单、文件哈希、桌面与手机尺寸的浏览器报告。
2. 通过游戏源码仓库的 `tools/stage-web-release.ps1` 将当期网页文件暂存到本网站的 `public/jianghu/`，同步更新 `src/data/siteData.ts` 内该游戏的中英文简介、版本、封面和入口。`public/games/jianghu/` 放置跳转首页，保留查询参数和片段。
3. 在网站工作树运行 `npm ci` 与 `npm run build`，比对 `dist/jianghu/` 和发行清单，再正常推送到 `master`。GitHub Pages 构建完成后，腾讯云静态发行流程生成 `production-site` 下载包。香港网站服务验证 SHA-256 后切换至新目录。
4. 通过 HTTPS 验证首页作品卡、游戏、工坊、别名入口和清单中各文件。确认退役的游戏资源已从当前目录撤出，再记录本次网站提交与线上基线。

## 存档与恢复

游客进度保存在当前浏览器。`/games/jianghu/` 和 `/jh` 会转到主入口，同一域名的游客可继续读取本机存档。换浏览器、设备或离线版时，可以在设置中导出和导入游客存档。账号进度由独立的 HTTPS 账号服务保存和结算，视觉更新可单独发布静态网页。

如需恢复服务，从已经核验且符合当前发布要求的备份中选取相应静态包，恢复该游戏目录、入口与作品卡，重新检查存档兼容性、资源清单和在线访问。
